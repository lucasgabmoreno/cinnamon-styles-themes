# Cinnamon Styles Themes
Simplify the complete installation of a theme with all its variations on the Cinnamon desktop. 

<img src="/img/styles.png" style="width:450px">

Copy and paste the command below each preview into the terminal. <br> It works on all Linux distributions and BDS systems.

<br>

## Themes

### Mint

CAPTURA

```
sudo curl -sL https://raw.githubusercontent.com/lucasgabmoreno/cinnamon-styles-themes/refs/heads/main/cinnamon-styles-themes.sh | sh -s -- mint
```
