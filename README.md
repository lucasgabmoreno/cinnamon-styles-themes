# Cinnamon Styles Themes
Simplify the complete installation of a theme with all its variations on the Cinnamon desktop. 

<img src="/img/styles.png" style="max-width:400px">

## Install
```
sudo curl -L https://raw.githubusercontent.com/lucasgabmoreno/cinnamon-styles-themes/refs/heads/main/cinnamon-styles-themes -o /usr/local/bin/cinnamon-styles-themes && sudo chmod +x /usr/local/bin/cinnamon-styles-themes
```
---

## Themes

### Mint defaults all
```
sudo cinnamon-styles-themes mint-defaults-all
```
